A scroll-snapping portfolio that shifts between **black, deep colour, white and light gray** as you move through sections. Click any card to expand it. Six switchable colour palettes (Burgundy, Blue, Green, Violet, Gold, Mono) in a translucent corner menu, a blog with dark and light modes, and no build step: plain HTML, CSS and JavaScript.

## Structure

```
index.html        main page
404.html          not-found page
css/              style.css · blog.css · palettes.css
js/               data.js (all content) · script.js · blog.js · palette.js · transition.js
blog/             blog1.html · blog2.html · blog3.html
assets/           og.png · icons/   (add photo.jpg and cv.pdf)
sitemap.xml · robots.txt · site.webmanifest · favicon.ico
```

## Run locally

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Customise

All text lives in `js/data.js`. Replace `yourname` in the URLs with your GitHub username, add `assets/photo.jpg` and `assets/cv.pdf`, and publish with GitHub Pages (*Settings → Pages → Deploy from branch → main / root*).
